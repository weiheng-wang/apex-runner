# Apex Runner

## Description
Python game for PyWeek 40 "skyscraper"

Evacuate to Apex City — the last safe haven on Earth. Only the rooftops stand between you and survival.

## How to Play
Run the game script:
   ```sh
   python3 game.py
   ```
## Controls
   - WASD/Arrow Keys to move
   - Space to jump
   - R to restart level
   - Left click and drag to move camera
   - Scroll to zoom
